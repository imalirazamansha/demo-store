🔐 MFA — Authenticator App

Platform admin ke liye doosri pehchan (MFA) zaroori hai. Pehle apne authenticator app (Google Authenticator / Authy) se 6-digit code dein.

Authenticator app se yeh QR code scan karein. Agar scan na ho, to neeche wala secret haath se daal lein.

Yeh secret sirf abhi dikh raha hai — dobara nahi dikhaya jayega. App mein add karne ke baad neeche 6-digit code likhein.

🔐 MFA — Authenticator App

Platform admin ka login ab magic link + authenticator code se hota hai. Yahan apne enrolled authenticator dekh aur manage kar sakte hain.
