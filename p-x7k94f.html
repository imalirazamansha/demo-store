🌐 Apna Domain Connect Karein

Domain load ho raha hai…

DNS instructions:
1) Apne domain provider (Namecheap/Hostinger) mein jayein.
2) CNAME record banayein: Host '@' ya 'www' → Target 'imalirazamansha.github.io' (GitHub Pages par abhi).
Note: Cloudflare shift ke baad target badlega aur Super Admin aap ko naya target dega.
3) DNS propagate hone mein 1–24 ghante lag sakte hain.
4) Jab domain khulne lage, Super Admin status 'live' karega.
Abhi hosting GitHub Pages par hai — custom domain tab live hoga jab Phase 2 (Cloudflare) complete hoga; tab tak domain 'pending' rahega.

🧩 Homepage Sections

Har section ko ⠿ handle se drag karke upar/neeche karein — store ka homepage bilkul isi tartib mein bane ga. 👁 toggle off karne se section store se chhup jayega. Neeche Custom Section se apna heading/text/image wala naya section bhi jor sakte hain. Save ke baad store reload karke dekhein.

ℹ️ Farq samajh lein: yahan sirf sections ki tartib + show/hide + custom sections hote hain. Built-in sections ke andar ka content (FAQ ke sawal, reviews, How-to-Order steps, budget tiles, trust strip, About text) Content tab mein edit hota hai.

🎨 Appearance
